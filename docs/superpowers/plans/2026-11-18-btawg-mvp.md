# BTAWG MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build two Linux binaries — `btawg-server` (VPS hub + 3x-ui-style web panel) and `btawg-client` (SOCKS5-only node with a real OS interface + overlay IP) — that carry AmneziaWG inside a BitTorrent carrier and discover the server strictly through DHT.

**Architecture:** One Go module `btawg/` with `cmd/btawg-server`, `cmd/btawg-client` and `internal/{carrier,bind,socks,config,store,dht,awg,panel}`. Client = real TUN (overlay IP, no default route) + AWG + SOCKS5 that chains to the server's egress SOCKS5 over the overlay; server = AWG hub + BitTorrent listener + DHT announcer + egress SOCKS5 + forwarding + web panel. Default carrier is `extended` (BEP 10) over pure-Go µTP no-Nagle (validated: +0.07 ms, nDPI=BitTorrent).

**Tech Stack:** Go 1.27, `github.com/amnezia-vpn/amneziawg-go/v3 v3.1.20261116`, `github.com/anacrolix/go-utp v0.0.0-20260908033909-9f1664acf866` (patched no-Nagle via `replace` → `third_party/go-utp`), `github.com/anacrolix/dht/v2`, `go.etcd.io/bbolt`, `golang.org/x/crypto`.

**Spec:** `docs/superpowers/specs/2026-11-18-btawg-mvp-design.md` (binding authority). Transport findings: `experiments/awg-bittorrent/FINDINGS.md`. Carrier reference implementation: `experiments/awg-bittorrent/cmd/bench/{carrier.go,extended.go,bind.go,transport.go}`.

## Global Constraints

- Go 1.27.0; pure-Go µTP only (no libutp); `CGO_ENABLED=0` builds must succeed.
- AWG profile default, verbatim: `jc=4`, `jmin=40`, `jmax=100`, `s1=32 s2=32 s3=32 s4=32`, `h1=101 h2=102 h3=103 h4=104`.
- Default transport value `"ext-utp"`; allowed values `"ext-utp"`, `"ext-tcp"`, `"req-utp"`, `"req-tcp"`. Never webseed, never bare AWG fallback.
- Import string prefix `btawg://`, base64url(JSON), and it MUST NOT contain any server public endpoint (no VPS IP/port field). It is a secret.
- Carrier framing: `BlockSize = 2048`; request/piece window 32; piece messages carry uint16 big-endian length prefix + AWG datagram + random tail padding to 2048.
- SOCKS5 server (client) binds `127.0.0.1`, no auth. Egress SOCKS5 (server) binds the overlay IP, no auth. Panel binds loopback by default.
- DHT is discovery-only (never a data relay); discovery failure must be an explicit error, not a hang.
- Match the benchmark's AWG profile string format used by `IpcSet` (field-per-line `name=value`).

## Review Focus

1. **Import-string leak:** a parsed `ClientConfig` must have no field that names the server's reachable endpoint; parsing a future `version` must error, not guess.
2. **UDP datagram integrity:** SOCKS5 UDP ASSOCIATE must preserve boundaries (fragment `0` only) and never merge/coalesce datagrams.
3. **Carrier robustness:** invalid BT message id/size must increment `Invalid` and close, never block forever.
4. **Revocation cleanup:** revoking a client must close its carrier and join its goroutines (no orphan socket/queue).
5. **DHT timeout:** `Discover` must return within a bounded timeout when DHT is unreachable, with a non-nil error.

type Transport interface {
    Send([]byte) error
    Recv() <-chan []byte
    Done() <-chan struct{}
    Close()
    Wait()
}

// Handshake performs the 68-byte BitTorrent protocol handshake on c using the

func Handshake(c net.Conn, infoHash [20]byte, peerID [20]byte) error

// NewRequestPiece wraps c with BEP 3 request/piece framing (ids 1/2/5/6/7).

func NewRequestPiece(c net.Conn, infoHash, peerID [20]byte, ownOdd bool) (Transport, error)

Differences from the bench: configurable `infoHash`/`peerID`, no `captureTCP`, no `wrapDelay`, no package-level `must`. Keep an exported stats getter only if needed — otherwise drop; keep `Invalid` as an internal counter surfaced via `Invalid() int64`.

type DialFunc func(ctx context.Context, network, addr string) (net.Conn, error)
// DialUDPFunc returns a fresh UDP socket through which the caller sends
// datagrams to arbitrary destinations (the caller supplies the SOCKS5 UDP
// header). Used by Server for UDP ASSOCIATE.
type DialUDPFunc func(ctx context.Context) (net.PacketConn, error)

type Server struct{ /* ... */ }
